      Why the system is built this way
      
        
      The model may propose structure, but retrieval and validation decide what can leave the API. That boundary keeps a fluent answer from becoming an unsafe answer.
      
      
      
      
      
        
      Grounding
      Reference records supply every troubleshooting instruction.
      
        
      Resolution
      Only exact masked URIs from the deeplink catalog are returned.
      
        
      Cache admission
      Only plans that already passed the full validator enter the fast path.
      
        
      Fallback
      Low-confidence complaints return a named failure instead of guessed steps.
